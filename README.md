# Marble Race 2D

A browser-based 2D marble race game.

## Features
- 15 racer slots.
- Every racer can have a custom name and image.
- 2D physics powered by Matter.js.
- One winner only: the first marble crossing the finish line.
- Adjustable gravity, marble size and race speed.
- Map editor: draw collision walls, delete walls, restore the default map.
- Save/load configuration as JSON.
- Browser localStorage automatically keeps racer and map changes on the same device.
- Responsive layout for desktop and mobile.

## Run
Open `index.html` or deploy the repository with GitHub Pages.

## Controls
- **Race** starts a countdown and race.
- **Edit map** enables map editing.
- In map editor, drag on empty space to add a wall; click an existing wall to delete it.
- **Save** stores the current configuration locally.
- **Load** imports a JSON configuration.
